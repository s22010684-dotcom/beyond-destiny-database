# Beyond Destiny Workflow Management System

Web-Based Wedding Studio Workflow Management System developed for Beyond Destiny as part of the EER4189 Software Design in Group module.

## Project Scope
The system manages post-wedding workflow activities including:
- Client and project management
- Task assignment
- Staff task tracking
- Employee workload monitoring
- Client follow-ups
- Package deliverables
- Final delivery tracking
- Role-based access control

## Technology Stack
- React
- JavaScript
- Tailwind CSS
- Node.js
- Express.js
- PostgreSQL
